# Sarvesh Kumar — Personal portfolio

A responsive personal website with light and dark themes, an interactive workflow demo, a skills explorer, scroll animations, and reduced-motion support.

Contact: **sarvesh.official@icloud.com**. The telephone number and original résumé are excluded.

## Hosting

GitHub Pages publishes this repository at https://sarvesh-kr.github.io/just-me/ after Pages is enabled.

In **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/ (root)**, then save.

## Editing

Edit `index.html`, `style.css`, and `app.js`. No installation or build step is required. Once Pages is enabled, changes pushed to `main` publish automatically.

Fonts load from Google Fonts with local system fallbacks. Theme and motion preferences are saved in the visitor’s browser. The workflow demonstration is illustrative and does not call external systems.
